# T23 — Quyền & cấu hình

## Kết quả

**PARTIAL chỉ vì chưa chạy ma trận thủ công trên điện thoại thật.** Phần code và
test tự động đã xong ở cả server kính, host và Android.

- Chốt transport `POST /api/v1/service/capabilities` → operation/action
  `capabilities_get`, dùng pipeline FCM/status hiện có; app/host cũ thoái hoá êm.
- Android trả đúng object `capabilities` gồm 10 khoá đóng. Đã thêm
  `play-services-location:21.3.0`.
- Bỏ quyền `CAMERA` thừa khỏi manifest và startup permission request theo yêu cầu
  người dùng. Action mở Camera hệ thống còn hoạt động bằng external intent, không
  cần app giữ quyền Camera.
- Server kính validate đúng tập khoá/kiểu, cache 300 giây theo `device_id`, prefetch
  lúc startup, cảnh báo `emergency_contact_set`/`call_phone` một lần mỗi phiên.
- Quyền phụ không chặn action. `emergency_call` là ngoại lệ và fail-closed khi
  cache chứng minh thiếu số khẩn cấp, quyền gọi hoặc vị trí `always`.
- Lỗi quyền buộc refresh snapshot; lỗi chung của `music_play` được đổi thành câu
  chỉ rõ thiếu "quyền đọc thông báo" khi cache xác nhận.
