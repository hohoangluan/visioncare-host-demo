### Lệch với task file
1. **Cờ `-H "Expect:"` bị thiếu trong lệnh curl mẫu ở task file mục 2.1.**
   Đúng như prompt đã cảnh báo trước: nếu chạy nguyên văn lệnh trong task file,
   curl sẽ tự thêm `Expect: 100-continue` (do body > 1 KB — ở đây body ~231 KB)
   và treo tới timeout vì server này không bao giờ trả `100 Continue`
   (`HUONG_DAN_SERVER.md:177` đã ghi rõ điều này, và script của tôi đã thêm cờ
   `-H 'Expect:'`). Nếu bỏ qua điều này, một lần curl treo sẽ dễ bị đọc nhầm
   thành "terminator không tới" — kết luận sai (false negative).
2. **Task file bảo dùng `curl -v --raw ... -o /dev/null`** để tìm `0\r\n\r\n`.
   Bản đo đầu tiên của tôi nói sai rằng `-v --raw` "không hoạt động" — **đã
   sửa lại sau review**: `-v` một mình không in byte khung chunked ra stderr
   (chỉ in header/metadata), nhưng cờ `--raw` **không** tắt việc đọc khung
   chunked — nó tắt "transfer decoding", nghĩa là dùng `-v --raw -o file` thì
   libcurl **giữ nguyên** byte khung chunked (kể cả `0\r\n\r\n`) **ở cuối file
   body** thay vì tự giải mã/loại chúng. Đã kiểm tay: `tail -c 40 file | xxd`
   sau khi chạy `-v --raw -o file` cho ra đúng hex `30 0d 0a 0d 0a` ở cuối
   file. Vậy lệnh mẫu ở task file **vẫn dùng được**, nó chỉ sai ở chỗ đổ body
   (và terminator) vào `/dev/null` — chỉ cần đổi thành `-o somefile` rồi soi
   đuôi file là thấy terminator, không cần đổi cờ. Tôi vẫn giữ
   `--trace-ascii` trong script vì nó gom cả header + chunk-size + terminator
   vào một chỗ dễ đọc trong một lần chạy, không phải vì `-v --raw` không làm
   được.
3. **Test fixtures đường dẫn task file gợi ý (`sample.wav`, `fixture.jpg`)
   không tồn tại.** Đã dùng `warm_melodic.wav` (repo root) và
   `tests/fixtures/space_room.jpg` theo đúng chỉ dẫn môi trường đã verify sẵn
   trong prompt.
4. Task file (và CONTRACTS mục 7 câu hỏi #4) coi đây là "một lệnh curl" —
   thực tế cần **hai** lệnh riêng biệt (localhost + tunnel) để so sánh, và cần
   nhớ đổi `-o /dev/null` thành một file thật rồi soi đuôi file đó (script
   dùng `--trace-ascii` để gộp mọi bằng chứng vào một nơi cho tiện đọc, không
   phải vì cờ gốc trong task file sai).
